GENERAL CHANNEL CONFIGURATION INFORMATION

- Each channel is defined in its own file. For a standard overview, see global.yml

- The channels "helpop" and "default" will exist no matter what, as they're internal plugin channels.

- (!) ALL CHANNEL CONFIGURATIONS MUST PROVIDE A CHANNEL TYPE AND DEFAULT FORMAT.

- Channel names are determined by the file name (<channel>.yml is named <channel>).
  You can override this by adding a name: <name> option.
